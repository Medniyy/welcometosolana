## Bridge to Solana

Welcome to Solana brings the first steps into one clear experience: choose a wallet, move assets through a supported route, review the transaction carefully, and find communities and applications once you arrive.

The interface currently brings together:

| Step | What it provides |
| --- | --- |
| **From everywhere** | 50+ source networks available across Squid and NEAR Intents |
| **Choose a wallet** | Direct paths to Jupiter, Solflare, Backpack, and Phantom |
| **Choose a route** | Embedded migration options with reminders to verify every transaction detail |
| **Find your people** | Starting points for community-led groups across Solana |
| **Explore** | A directory of applications, communities, and tools built on Solana |

Users keep control of their funds. Before signing, always review the token, amount, destination network, receiving address, fees, and minimum received. Provider links are not endorsements.

## Public identity

The site pairs **[Newsreader](https://fonts.google.com/specimen/Newsreader)** for editorial display typography with **[Manrope](https://fonts.google.com/specimen/Manrope)** for interface and reading text. Its visual language combines a near-black ocean foundation, frost-cyan light, concentric portals, and a centered path toward the horizon.
